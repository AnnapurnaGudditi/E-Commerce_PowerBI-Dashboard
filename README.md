# 🛒 E-Commerce Sales Performance Dashboard

## Overview
Interactive sales dashboard built in Power BI analyzing
Indian e-commerce data across 2018-2019.

## Tools Used
Power BI Desktop, DAX, Power Query

## Dataset
E-Commerce Dataset from Kaggle
- 560 orders across 19 Indian states
- 1500 order line items
- 3 product categories

## Dashboard Features
✅ 4 KPI Cards — Revenue, Profit, Orders, Target %
✅ Sales by Category bar chart
✅ Top 10 Sub-Categories by Profit
✅ Monthly Revenue vs Target line chart
✅ Top 10 States by Revenue
✅ Top 10 Customers by Revenue
✅ Profit share donut chart
✅ Interactive Year, Category and State slicers

## Key Business Insights
1. Total Revenue — Rs 4,31,502
2. Total Profit — Rs 23,955
3. Profit Margin — 5.55%
4. Clothing generates highest revenue
5. Maharashtra is top performing state

## DAX Measures Created
Total Revenue, Total Profit, Total Orders,
Profit Margin %, Avg Order Value,
Target Achievement %, Total Target
